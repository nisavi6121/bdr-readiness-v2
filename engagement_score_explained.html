1 Keep only genuine actions

Every event with status Sent (automated) is dropped. Only Attended / Responded / Clicked-type events count toward the score.

2 Old activity decays (30-day half-life)

recency = the decay of your freshest event in that channel. One recent event sets recency high; older events don't raise it.

# age_days = today − response_date
decay = exp( −ln(2)/30 × age_days ) = 0.5 (age_days / 30)
recency = max( decay ) over the channel's genuine events
recency_score = recency × 100

4 Sum channels, then normalize

Per-channel scores sum into raw_engagement_signal, then divide by the 95th-percentile ceiling within entity type → 0-100. Top 5% saturate at 100; one outlier can't squash everyone.

3,990 ÷ 1,452 = 2.7 → clipped → engagement_score = 100. The two stale single-touch channels contribute nothing — decay killed them.

Note — volume doesn't decay (a known seam). Recency uses only the freshest event, but volume is a raw lifetime count — so an event from a year ago still adds to volume as long as there's one recent event to give recency. The multiplication protects the worst case (no recent activity → recency ≈ 0 → score ≈ 0), but old history can quietly re-credit itself, which slightly undercuts the "recency over depth" principle.

Fix I'd make: recency-weight the volume (sum of decays) or use the meaningful_30d / 90d windows already computed in 02_features.py — so old events stop earning full volume credit.
